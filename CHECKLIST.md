# Acceptance checklist

- [ ] Read the source/scope notice and inspect both main package inventories.
- [ ] Run structural validation, tests, and the installer/deployer dry runs.
- [ ] Test first in a separate user profile or keep a working recovery TTY.
- [ ] Install the selected Arch packages and review AUR builds.
- [ ] Install Caelestia and test a manual Hyprland session.
- [ ] Deploy the overlay and locate any timestamped backups.
- [ ] Check the Arch terminal logo, Firefox preference, and standard cursor.
- [ ] Check the separate wallpaper directory and dynamic colour scheme.
- [ ] Check GUI authentication, audio, networking, lock, and suspend/resume.
- [ ] Enable SDDM only after the session works; inspect other local overrides.
- [ ] Reboot and verify password login with no unintended autologin.
- [ ] Keep disk/boot/Wi-Fi examples opt-in and hardware-appropriate.
